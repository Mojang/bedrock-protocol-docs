# DataDrivenUIShowScreenPacket

- Added the ClientboundDataDrivenUIShowScreenPacket to show a DataDriven UI screen at client side.
  - ScreenId. The screen identifier to show. Max allowed length 500 characters.

# DataDrivenUICloseAllScreensPacket

- Added the ClientboundDataDrivenUICloseAllScreensPacket to close all DataDriven UI screens at client side.
