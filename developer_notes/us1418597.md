# LevelChunkPacket
- Converted `LevelChunkPacket` to Cereal (`CerealOnly` mode). The binary wire format has changed and is not backwards compatible with prior protocols. The subchunk-count sentinel encoding is replaced with a regular varint count plus an optional client request limit, and `mCacheMetadata` is now always present on the wire as a length-prefixed vector (empty when caching is disabled) instead of being omitted via a conditional.
