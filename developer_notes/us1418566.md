# ClientCacheBlobStatusPacket

- Converted `ClientCacheBlobStatusPacket` to Cereal. Cereal becomes the wire format under `SemanticSideBySide_LogOnMismatch`. The encoding interleaves each vector's element count with its element data instead of writing both `Missing` / `Found` counts before either vector, so prior-protocol decoders cannot parse the new wire format.
