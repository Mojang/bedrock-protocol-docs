# PlayerListPacket
- Converted `PlayerListPacket` to Cereal (`CerealOnly` mode). The binary wire format has changed and is not backwards compatible with prior protocols. Entries are now a tagged variant over `AddEntry` and `RemoveEntry`, dispatched per-entry instead of via a single top-level `Action` byte; this removes a crafting vector where a mismatched top-level action would trigger `brstd::bad_variant_access` on the receiver.
