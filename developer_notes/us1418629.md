# SetScoreboardIdentityPacket
- Converted `SetScoreboardIdentityPacket` to Cereal (`CerealOnly` mode). The binary wire format has changed and is not backwards compatible with prior protocols. The packet-level `mType` (`Update`/`Remove`) is still serialized; what changed is that `mPlayerId` is now gated per-entry by an `optional<int64_t>` presence byte instead of the legacy `writeIf` conditional keyed on the packet type.
