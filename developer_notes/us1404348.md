# AddActorPacket
- Converted `AddActorPacket` to Cereal (`CerealOnly` mode). The binary wire format has changed and is not backwards compatible with prior protocols. Each entry in the synched actor data list is now emitted as a tagged variant payload (discriminator + value) rather than the legacy hand-rolled `DataItem` byte stream, so prior-protocol decoders cannot parse the new format.
