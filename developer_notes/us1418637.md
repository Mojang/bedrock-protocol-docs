# SubChunkPacket
- Converted `SubChunkPacket` to Cereal (`CerealOnly` mode). The binary wire format has changed and is not backwards compatible with prior protocols. Conditional fields driven by `mResult` and `mCacheEnabled` are now bound as `brstd::optional<T>`, each preceded by a presence byte rather than implied by the surrounding enum. `SubChunkRequestPacket`'s `SubChunkPosOffset` is also reflected through Cereal as part of the same migration.
