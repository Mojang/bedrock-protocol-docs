# PlayerAuthInputPacket
- Converted `PlayerAuthInputPacket` to Cereal (`CerealOnly` mode). The binary wire format has changed and is not backwards compatible with prior protocols. ADO:1404359
- The shared `ItemStackNetIdVariant` cereal binding now projects the variant to and from its canonical single signed-VarInt encoding (non-negative selects the server-issued net id, negative-odd selects the client request id, negative-even selects the legacy client request id) instead of cereal's default tagged-variant encoding, which also wrote an explicit alternative index. This corrects the on-wire bytes and the generated schema (a plain integer rather than a polymorphic `anyOf`). Because the binding is shared via `NetworkItemStackDescriptor`, the same correction applies to other packets that embed item-stack net ids (for example `InventorySlotPacket`, `MobEquipmentPacket`, `AddItemActorPacket`).
