# PlayerUpdateEntityOverridesPacket

The payload is now a tagged variant over `ClearOverrides`, `RemoveOverride`, `SetIntOverride`, and `SetFloatOverride` so each variant's `Value` is part of the alternative's schema instead of an out-of-band conditional.
