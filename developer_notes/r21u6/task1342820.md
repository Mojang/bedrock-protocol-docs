# ConnectionRequest
- Added GraphicsMode to the connection request and sub client connection request to see what graphics mode the client is using.

# UpdateClientOptionsPacket
- Added a packet that's sent when client options are changed, currently only supports graphics mode.
- Contains a boolean describing if the client has a graphics mode change followed by the new graphics mode if it was changed.
- Graphics mode is stored as an int
    - Simple = 0, Fancy = 1, Advanced = 2, RayTraced = 3.
