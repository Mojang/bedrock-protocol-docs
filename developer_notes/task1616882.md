# PresenceConfiguration field removal
- Removed unused `mExperienceName` and `mWorldName` string fields from `PresenceConfiguration`. Only `mRichPresenceId` remains.
- `PresenceConfiguration::mRichPresenceId` changed from `std::string` to `brstd::optional<std::string>` so that absence is expressed by `nullopt` rather than an empty string. Schemas now reject empty `richPresenceId` values via `rejectEmpty()`.
- This affects `ServerPresenceInfoPacket` and `ServerConfigurationJoinInfo` which carry `PresenceConfiguration`.
