# ClientboundDataDrivenUIShowScreenPacket
- Added optional `DataInstanceId` field (uint32) to associate a data instance with the displayed screen.

# ClientboundDataDrivenUICloseScreenPacket
- Renamed from `ClientboundDataDrivenUICloseAllScreensPacket`.
- Added optional `FormId` field (uint32) to specify which form to close. If not provided, all Data Driven UI screens will be closed.

# ServerboundDataDrivenScreenClosedPacket
- Added new packet to notify the server when the client has closed a Data Driven UI screen.
- Contains `FormId` field (uint32) to identify which form was closed.
- Contains `ClosedReason` field to indicate why the screen was closed (user action, server request, or error).
