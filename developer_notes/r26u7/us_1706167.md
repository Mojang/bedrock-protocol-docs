# ClientboundMusicPlaybackFailurePacket
- Added `ClientboundMusicPlaybackFailurePacket` with ID 364 to report music discs that could not play. Its `Failures` list holds one `MusicPlaybackFailureEntry` per disc, with a `State` and the song's `Description` ADO:1706167

# MusicPlaybackState enum
- Renamed `MusicPlaybackSource` to `MusicPlaybackState`. `Local` stays 0 and `Online` stays 1 ADO:1706167
- Added `NotFound` = 2 for sound events the server has no definition for, and `Pending` = 3 for sound events it has no definition for yet because it is not ready to verify registered audio content ADO:1706167

# ClientboundOnlineMusicPlaybackResponsePacket
- Renamed the `Source` field to `State` without changing the wire layout ADO:1706167

# TextPacket
- Added a non-required `Queue?` boolean after `Parameter List` in the `MessageAndParams` body used by `Translate`, `Popup`, and `JukeboxPopup`. It defaults to `false`. For `JukeboxPopup`, `true` queues the popup behind the one currently showing, and `false` shows it immediately and clears the queue ADO:1706167
