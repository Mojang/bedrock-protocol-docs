# ClientboundAttributeLayerPacket
- Added `ClientboundAttributeLayerPacket` for sending attribute layer data from the server to the client during initialization and when a new layer is added. ADO:1537281
# ClientboundAttributeLayerSettingsPacket
- Added `ClientboundAttributeLayerSettingsPacket` for syncing attribute layer minor changes from the server to the client. ADO:1537281
# ClientboundEnvironmentAttributeUpdatePacket
- Added `ClientboundEnvironmentAttributeUpdatePacket` for syncing the state of environment attributes from the server to the client when they change or are added to an attribute layer. ADO:1537281
# ClientboundEnvironmentAttributeRemovePacket
- Added `ClientboundEnvironmentAttributeRemovePacket` for removing environment attributes on the client when they are removed from attribute layers on the server. ADO:1537281
