# Network Protocol

* Converted `CraftingDataPacket` to Cereal-only serialization. The binary wire format has changed and is not backwards compatible.
* Recipe data now serializes as separate vectors by recipe shape/type (`Shaped Recipes`, `Shapeless Recipes`, `Multi Recipes`, chemistry recipes, smithing recipes, mixes, reducers, and `Clear Recipes`) instead of the old tagged `CraftingDataEntry` union. Furnace recipe entries remain removed and are represented through the normal recipe collections.
* `RecipeUnlockingRequirement` is now fully reflected through Cereal rather than being transported as an opaque `Serialized Unlocking Requirement Data` byte blob. The wire encoding consists of an `Unlocking Context` enum (`None`, `AlwaysUnlocked`, `PlayerInWater`, `PlayerHasManyItems`) followed by an optional `Unlocking Ingredients` list that is only present when the context is `None`. The generated protocol schema now describes the enum values and ingredient list directly.
