# Network Protocol

* Converted `ItemStackResponsePacket` to Cereal-only serialization. The binary wire format has changed and is not backwards compatible.
* Responses now serialize as a reflected `Responses` vector. Each response contains a result, client request ID, and reflected container/slot data.
* Cross-field invariants are now encoded directly in the cereal binding rather than described in help text:
    * `ItemStackResponseInfo.Containers` is an optional that carries a value **iff** `Result == Success`. A single presence byte is always written; the container payload follows only for success responses.
    * `ItemStackResponseSlotInfo.Item Stack Net Id` is an optional that carries a value **iff** `Amount > 0`. A single presence byte is always written; the net ID value follows only for non-empty slots.
    * `Durability Correction` carries an explicit `int16_t` range constraint that matches the underlying storage and the historical wire range.
