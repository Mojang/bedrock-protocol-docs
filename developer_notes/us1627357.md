# PlayerLocationPacket
- Converted `PlayerLocationPacket` to Cereal (`CerealOnly` mode). The binary wire format has changed and is not backwards compatible with prior protocols. The payload is now a tagged variant over `CoordinatesLocation` (carries a `Vec3`) and `HiddenLocation` (no payload), replacing the legacy `(Type, optional<Vec3>)` pair that allowed invalid combinations.
