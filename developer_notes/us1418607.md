# MoveActorDeltaPacket
- Converted `MoveActorDeltaPacket` to Cereal (`CerealOnly` mode). The binary wire format has changed and is not backwards compatible with prior protocols. The 16-bit packed header is replaced with reflected bindings: the six payload-bearing fields (position xyz, rotation xy/y-head) are `brstd::optional<T>` whose presence drives the matching header flag, and the four remaining flag bits are standalone booleans.
