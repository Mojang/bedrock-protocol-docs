# AddPlayerPacket
- Converted `AddPlayerPacket` to Cereal (`CerealOnly` mode). The binary wire format has changed and is not backwards compatible with prior protocols. The entity-data payload inherits the tagged-variant encoding introduced for `AddActorPacket` (see `us1404348.md`), and the abilities, property-sync, and link payloads are now emitted via their cereal-bound schemas, so prior-protocol decoders cannot parse the new format.
- The `Carried Item` is now captured from the player's selected item via `ItemStack::getStrippedNetworkItem()` (item/count/aux/networkUserData/chargedItem), so the item-stack net id variant carried by the legacy descriptor is no longer included. `getStrippedNetworkItem()` also strips the item's network user data (it empties the `ench` enchantment list and removes `RepairCost`); the empty `ench` key is preserved so enchantment glint still renders. This is intentional: neither the net id nor the full user data is meaningful for a remote player's display item.
