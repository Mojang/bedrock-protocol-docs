# ClientboundMapItemDataPacket
- Converted `ClientboundMapItemDataPacket` to Cereal (`CerealOnly` mode). The binary wire format has changed and is not backwards compatible with prior protocols. The legacy `mType` bitmask and its eight unconditional payload fields are replaced with `brstd::optional<T>` projections whose presence drives the matching `Type` bit on read, and `MapItemTrackedActor::UniqueId` is rebound with optionals so the schema documents per-type presence.
