# StructureBlockUpdatePacket
- Converted `StructureBlockUpdatePacket` to Cereal (`CerealOnly` mode). The binary wire format has changed and is not backwards compatible with prior protocols. The packet payload and its nested `StructureEditorData` are now serialized via declarative Cereal bindings, and the structure name is emitted as a nested redactable string (`Unredacted`/`Redacted`) rather than the legacy flat unredacted/filtered string pair, so prior-protocol decoders cannot parse the new format.
