# NetworkSettingsPacket

- Servers can now tell clients which recovery profile to use when retrying lost data ADO:1719188
  - `Default` keeps current behavior; `Balanced` and `Fast` allow shorter delays before retrying lost data
  - Clients apply the profile without reconnecting
- Added a required byte after the client throttle scalar: `Default` = `0`, `Fast` = `1`, `Balanced` = `2`; packets with missing or unknown values are rejected ADO:1719188
