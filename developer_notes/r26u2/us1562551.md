# ServerStoreInfoPacket and ServerPresenceInfoPacket
- Added `ServerStoreInfoPacket` to send `ClientStoreEntryPointConfiguration` from server to client.
- Added `ServerPresenceInfoPacket` to send `PresenceConfiguration` from server to client.
- These packets send mutable configuration data separately from immutable data like gatherings information.
- Only mutable data (client store and presence configuration) is sent via these new packets, preventing unnecessary transmission of immutable gatherings data.
