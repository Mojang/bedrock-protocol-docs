CameraSplineDefinition

Field Name Type Field Index Description
name (Required) string 0 The identifier for this spline, in "namespace:name" format.
total_time (Required) float 1 The total time, in seconds, to play back the spline.
spline_type string 2 The spline interpolation type: "catmullrom" or "linear". Defaults to "catmullrom".
control_points (Required) array<CameraSplineControlPoint.json> 3 Array of control point positions, each as [x, y, z] in world space.
progress_key_frames (Required) array<CameraSplineProgressKeyFrame.json> 4 Key frames where each entry defines a progress alpha [0-1] and a time (in seconds) when the spline should reach that progress.
rotation_key_frames (Required) array<CameraSplineRotationKeyFrame.json> 5 Array of rotation key frames, each with a rotation value and the time (in seconds) when it should be applied.
