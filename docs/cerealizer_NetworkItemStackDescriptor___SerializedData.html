cerealizer<NetworkItemStackDescriptor>::SerializedData

Field Name Type Field Index Description
Id (Required) int16 0 Send fixed Id of 0 for invalid item
Stack size (Required) uint16 1 The number of items in the stack. Must be within the item's allowed stack size range.
Aux value (Required) varuint32 2 Item auxiliary/metadata value. Used to distinguish item variants. Ignored for block items where aux is always 0.
Net Id Variant ItemStackNetIdVariant.json 3 Optional network ID variant used to track item stack identity across client and server.
Block Runtime Id (Required) varuint32 4 Runtime block state ID associated with this item when it represents a block. Used to identify the exact block state placed when the item is used.
User Data Buffer (Required) string 5 The @ItemInstanceUserData.html#ItemInstanceUserData@ binary blob encoded as a String, so it's unsigned varint length prefixed. Get all your nbt+property bytes, calculate the length, write that length, THEN write the data.
